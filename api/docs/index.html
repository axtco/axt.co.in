API Reference

Welcome to the AXTCloud API v1. Automate your infrastructure.

The AXTCloud API is built on REST principles. It allows you to programmatically manage your VPS instances, dedicated servers, and storage buckets. All API access is over HTTPS, and accessed from:

Base URL 
https://api.axt.co.in/v1

Authentication

Authenticate your API requests by including your API key in the Authorization header of every request. You can generate and manage API keys in the Cloud Console under "API Settings".

Header Format 
Authorization: Bearer YOUR_API_KEY

Errors & Status Codes

AXTCloud uses standard HTTP response codes to indicate the success or failure of an API request.

CodeMeaning
200OK - Request succeeded.
201Created - Resource created successfully.
400Bad Request - Invalid parameters.
401Unauthorized - Invalid API key.
404Not Found - Resource does not exist.
429Too Many Requests - Rate limit exceeded.
500Server Error - Something went wrong on our end.

List Instances

GET /instances

Retrieve a list of all VPS instances associated with your account.

curl -X GET "https://api.axt.co.in/v1/instances" \
  -H "Authorization: Bearer YOUR_API_KEY"
const axios = require('axios');
axios.get('https://api.axt.co.in/v1/instances', {
  headers: { Authorization: 'Bearer KEY' }
});

Create Instance

POST /instances

Deploy a new VPS instance asynchronously.

Parameters

ParameterTypeDescription
nameREQUIRED string The hostname for your server.
regionREQUIRED string mumbai, singapore, or frankfurt.
planREQUIRED string Slug (e.g., micro-core, prime-core).
imageREQUIRED string OS image (e.g., ubuntu-22-04). 
curl -X POST "https://api.axt.co.in/v1/instances" \
  -H "Authorization: Bearer KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "web-server-01",
    "region": "mumbai",
    "plan": "prime-core",
    "image": "ubuntu-22-04"
  }'

Instance Actions

POST /instances/{id}/actions

Perform power operations (reboot, shutdown, power on) on an instance.

curl -X POST "https://api.axt.co.in/v1/instances/vps-123/actions" \
  -H "Authorization: Bearer KEY" \
  -d '{ "type": "reboot" }'

Delete Instance

DELETE /instances/{id}

Permanently destroy a server and all its data. This action cannot be undone.

List Buckets

GET /storage/buckets

List all Object Storage buckets in your account.

curl -X GET "https://api.axt.co.in/v1/storage/buckets" \
  -H "Authorization: Bearer KEY"

Create Bucket

POST /storage/buckets

Create a new S3-compatible bucket.

curl -X POST "https://api.axt.co.in/v1/storage/buckets" \
  -H "Authorization: Bearer KEY" \
  -d '{ "name": "my-backups", "region": "sg" }'

List Invoices

GET /billing/invoices

Retrieve a history of all generated invoices.

curl -X GET "https://api.axt.co.in/v1/billing/invoices" \
  -H "Authorization: Bearer KEY"
